Findings
1. [resolved] Naively scaling #APEX-7 tuning (kHeading/kCross/lookahead/overtakeGain/
   minGap) for aggressive tiers pushed high-skill cars off the ribbon and below the
   2 m separation floor. Fixed by (a) making reaction/aggression deliberately mild so
   `skill` stays the dominant pace axis, and (b) enforcing the same soft roadside
   barrier as the visible race inside `simulateRace` (shoulder 0). Verified by
   tests/difficulty.test.ts AC4 + the report (off=0, minSep>2.35 on every tier).
2. [resolved] `reaction` was first mapped to a longer lookahead for low tiers, which
   made "easy" cars *faster* than the reference. Fixed: reaction only tightens
   kHeading/kCross (never shortens/lengthens the lookahead).
3. [resolved] `boundedCatchUp` originally only guarded a non-finite gap; a non-finite
   base skill still produced a non-1 ratio. Fixed to return ratio 1 (unassisted).
4. [resolved] An in-field reference got stuck behind slower cars, making the balance
   signal traffic-bound. Fixed: the reference is a solo ghost pace car outside the
   collision field, so it measures pace and cannot perturb the pack.
5. [checked] Determinism: no Math.random/Date.now; rng consumed only when a random
   skill is needed; tiered race reproduced bit-for-bit (tests AC7).
6. [checked] Back-compat: omitting tier/player reproduces the #APEX-7 result exactly
   (tests AC7); the soft barrier is a no-op for the compliant default field.

Architecture / security / performance
-------------------------------------
- Clean layered design: pure `difficulty.ts` table + bounded scalar; the race sim
  gains an isolated solo reference; the visible scene reuses createRaceField. No
  `three.js`/DOM in src/ai. Dependency direction is sane (types -> difficulty typed
  only; difficulty -> driver value import; no runtime cycle).
- Security: `?difficulty=` is allow-listed via `coerceDifficultyTier` (fail-safe to
  normal); every numeric entry point is finite-guarded; `setCatchUp` clamps to
  [0.5,2]; no new sink, no secrets, no deps.
- Performance: `stepAndMeasure` adds one extra `project` per car per step
  (refreshProgress); containment is O(spline) but runs only on ribbon overflow. The
  full 25-seed x 6-stage x 4-tier report runs in seconds; acceptable.
