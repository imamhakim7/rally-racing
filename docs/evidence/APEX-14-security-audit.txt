1. location.search (?forceUnsupported=1) — untrusted URL.
   code: src/main.ts:68 `get("forceUnsupported") === "1"` — strict literal match.
   The branch calls `forcedUnsupportedAssessment()` with a CONSTANT reason and never
   echoes any part of the query string. No injection path.
2. WebGL driver strings (vendor/renderer) — untrusted driver input.
   code: src/engine/capabilities.ts:120-127 capture only; grep confirms they are never
   written to the DOM or any attribute (only kept in the GlCapabilities object).
3. Boot exception text (String(error)) — rendered as a TEXT node via
   supportScreen.mountSupportScreen (`summary.textContent`), never HTML.
4. Capability labels (missing/degraded) — app constants → `data-missing` setAttribute.
